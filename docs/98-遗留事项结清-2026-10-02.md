## ② 512²/501 身份终判 — ✅ 结清（重大修正）

**判定：501 = 环境反射 cubemap（TextureCubeArray，6 面 × 512²，mips=1，RGBA16F，ColorTarget|ShaderRead）。**
**既不是平面反射 RT，也没有 mip 链 → "水面平面反射（最强候选）"降级为弱候选，"不同 mip"假设彻底否证。**

证据链（四层，全部落盘）：

1. **资源身份**：`GetTextures()` 全表 → `TextureType.TextureCubeArray` / `cubemap=True` / `arraysize=6` / 512² / `mips=1` / RGBA16F；509 = 普通 512² D24S8（`cubemap=False`）。探针：`%TEMP%\opencode\rdc_probe_rtv.py`（log 同名）。
2. **面级布局**（探针 `rdc_probe_slice.py`）：A 批 ev124–281 → `firstSlice=5 / view 507`；批间 Clear ev292/293 绑定态同为 slice5/view507；B 批 ev335–1956 → `firstSlice=1 / view 503` → **两批写不同 cube face**。
3. **像素终判**（探针 `rdc_probe_pixels.py` / `rdc_probe_time.py`，`GetTextureData` 时点随 `SetFrameEvent`）：
   - ev13：slice5 = uniform（已被 ev12/13 清）、slice1 有内容；
   - **ev334（批间 Clear 后、B 批前）：slice5 md5 与 ev281 相同 → A 批内容未被 Clear 抹掉、存活；slice1 变 uniform → 批间 Clear 真目标 = slice1**（绑定态显示 slice5 → **绑定态≠清屏目标，第四次实锤**）；
   - ev1956 后 slice1 有内容；帧末 6 个 slice md5 全不同、全部有内容。
4. **消费链**（pass6 `-Targets`）：501 → S1 19 处读取 / S4 16 处（= 独立 16-Draw 段 ev39270–39502，RT0=585、DS=461，PS 15478×1 + 15990×4 + 17352×11，位于折射拷贝 ev39225 之后、透明/水段 ev39585 之前；输出 585 → ev39530 的 PS 17586 并回 321）/ S5 3 处；消费者 = PS **15478 / 15607 / 17352**，其中 **17352 声明 `dcl_resource_texturecube t3`**（`S1-pass6-ps-disasm.txt:348`）→ 按 cubemap 采样直证。同批 Draw 另读 520 深度、324 折射拷贝、661/665 960×540。
   - S2 室内 pass5 全帧无 512² 段 → 户外条件（反向坐实，S4 遗留 3 原文维持有效）。
5. **viewport 排除项**：A/B 批 viewport 全 512²（pass5 v4 + 探针）→ 尺寸恒定，排除"不同 mip 渲染"可能（连带支撑 ④）。
