### 关键差异与新判定

1. **室内不跑 VL（17607/17608）与全 res 标量模糊（17504/17505），而且根本没创建**：pass1 compute 列表 = [幻影0, 17506, 17507, 17510, 17511, 17518]，5 个真实 CS 全部被 dispatch → **引擎按需创建 CS**，户外专属效果连管线都不建
2. **效果归属更新**：17504/17505（全 res 标量 + 深度守卫）为**户外专属** → 排除 SSAO（室内必跑）与 bloom（17506/07 已覆盖，且室内火把仍需 bloom）→ 候选收窄为**太阳光轴遮蔽 / 大气雾 / 天空类**；17607/17608 VL 户外专属（无日光）自洽
3. 17510/17511（1/4 res、深度守卫、平滑混合）室内外都跑 → **常开后处理**（DOF 链候选维持）
4. **17518 依旧空跑**：不变量是矩形参数 cb0[0..1]=0（S2 室内帧采样区恰全零；S1/S3 户外帧帧全局非零——原"CB 全 0"措辞已修正）→ 引擎固定 dispatch 的可选格式转换 blit（RGBA16F→R11G11B10），移植时可条件化省略
5. **CB 帧级共享区室内全 0**（S1 的 vec4[2..5] 太阳方向、vec4[20..23] 体素域/眼位置，S2 均为 0）→ 576B 帧级 CB 按场景填充，VL 字段室内不初始化
6. **上述资源 ID/尺寸/格式与 S1 逐位一致**（461 深度、665/669/661、528⇄359、321/329）→ 启动期主链资源跨场景稳定（对 Vulkan 描述符/资源别名设计是利好）；⚠️ S3 复核补充：3D 噪声纹理 ID 跨抓帧不同（同槽同规格）→ **ResourceId 是抓帧局部量**，跨场景对齐用 (绑定槽, 尺寸, 格式, 哈希)
7. 引擎依旧无 PIX 标记（命名动作仅 `Present(ResourceId::35)`@22902），dispatch 上下文相邻事件全为 Drawcall → pass 归属靠资源链判定的方法不变
