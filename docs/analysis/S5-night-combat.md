### 核心结论：S5 专项（粒子 / 动态光 / 透明混合）

1. **粒子 pass 的 RT 组合** = 透明段 MRT×3（321 RGBA16F 场景色 + 582 R8G8 + 336 RGBA16F）/ 461 深度，与 S2/S4 完全同一组合 → 移植时透明 pass 可与 S2/S4 共用一套 renderpass 设计。
2. **透明段规模序列**：S3≈100 < **S5 122** < S2 159 < S4 242。S4 的 242 水主导（2612×175）；S5 无水（2612 仅 10）→ 122 ≈ S3 无水基线 + 夜战粒子增量，10325×46 为主导粒子 shader。
3. **夜间动态光形态** = Draw 侧而非 Dispatch 侧：483 点光源阴影 4 槽（16/15/11/15）+ 槽间 3 清 + 352/333 条件段；98 dispatch 与白天完全相同。
4. **9 CS 第五次场景无关实锤**（含夜间）：disasm 正文逐字节相同。

### CB 与调度

- 17504/05 cb0 头部 = texel (1/1920, 1/1080) + 方向向量组；cb0_80_95f = `[320,192,90]` 体素域回显（场景无关）+ 位置两组 `(24766.5, -7804.7, -3080.3, 0.1)` / `(24766.5, -7880.0, -3095.4, 6.0)`（随场景移动）+ 雾参 `0.85/0.85/0.3`（与 S4 同值）。
- 17607 cb0 前 16 float = 视图矩阵行组（0.909414, -0.415893… / 0.358234, 0.783334, -0.508075…），含方向向量与平移 (-15.0006…)；帧全局常量模式与 S1/S4 复现一致。

### Vulkan 移植注记（S5 增量）

- **点光源阴影 atlas** = 多槽位同资源 + 槽间 Clear → Vulkan 用 array/layer 划分或槽间 `loadOp=CLEAR` 的 renderpass 细分；批数动态（1~4+）意味着槽位表需按帧光源数分配。
- **暗场景条件帧图分支**：352/333/43702 这类条件段与 VL、466 拷贝同属"按光照条件开关"的帧图节点 → 条件化帧图需覆盖暗环境分支（与 S7 压测对照后定稿）。
- 粒子透明段与 S2/S4 同 MRT → 统一透明 renderpass；粒子 PS 侧无新槽位形态。
- UI 段 Draw 量波动大（14→58）→ UI pass 按动态 command 数记录，不入固定管线预算。
- 512² **= 环境反射 cubemap（501，6 面 cube-array，2026-10-02 终判）**：户外条件常驻（无水入镜仍渲）、被水面/透明段 PS 以 `texturecube` 采样 → Vulkan 侧按条件节点常驻分配，升分辨率/更新频率属水体现代化项（docs/03 §6.1）。
