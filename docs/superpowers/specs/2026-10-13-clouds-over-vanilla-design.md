# 2026-10-13 天空路线重设计：体积云叠加原版天空（Clouds-Over-Vanilla, CoV）

状态：待用户批准（brainstorming 产物，批准前不写产品代码；builder 预审 7 问已裁定，见各节）

## 1. 背景与动机

- T6 按「自研大气模型全替换天空」路线执行完毕（多轮修复与复审、3 次游戏会话）；第三次会话（v0.18.40）用户判定「没变化」——止损成立。
- 根因（复盘）：错误集中在**输入层**而非模型层——
  - 假太阳：以 skyIn 亮度三次方加权猜方向、屏幕锚定（Option A 裁定的产物）；
  - 伪世界光线：云 march 无相机旋转（sky_cloud.frag 明注「本仓没有相机矩阵入向」）；
  - 亮度体系：以自研散射 LUT 的参考 texel 归一到屏均值，三轮追着自己的尾巴修（天顶改背阳中天、软膝压缩、多重散射填充……）。
- 用户裁定（2026-10-13）：视觉优化系列参考 CommunityShaders（下称 CS）设计，走自己的实现；增强不替换；GPL-3.0 红线保持——只参考设计与参数结构，不复制代码行。

## 2. 侦察结论（事实基础）

- 游戏运行时：**SE 1.5.97.0 + SKSE 2.0.20**（日志核实）⇒ 原版天空 = 经典梯度天气着色器 + 2D 滚动云层 + 太阳盘/星星。增强路线的基底成立。
- 本插件架构（仓内核实）：
  - 构建 = GitHub Actions 单条 cl 两文件行（main.cpp + vkrenderer.cpp，user32.lib），无 CMake / CommonLib / skse 库 / Address Library；SKSE 走手写 skse_abi.h 原始 ABI。
  - 游戏对象访问 = 零（无 RE:: / GetSingleton）；全部能力 = D3D11/DXGI 拦截 + GPU 读回。
  - 相机四元数（qchain）已能从 VS 常量缓冲槽扫描正交重建（camdump 基建），**但被 ssr 门控**（sky-only 会话不捕获）；平移列在 dump 字节里存在但从未解析；fov/near/far 为手工反解后写 ini。
  - skyIn = 段 7 末 321（RGBA16F，原版天空已渲染、tonemap 前）——增强合成的理想基底与环境色采样源。
- CS 设计层参考（未复制代码）：SkySync 通过游戏对象拿真太阳/月亮方向、气候日出日落、游戏时刻，写入共享常量供 shader 使用；昼/夜光源切换使「当前投影光源方向」白天 = 太阳、夜晚 = 月亮。CS 的「物理天空」同在规划中（Linear Lighting PR 原话为铺路），其哲学是增强不替换。

## 3. 目标 / 非目标

**目标**

1. 体积云视觉可信：世界锚定（真相机朝向 + 真日/月方向），颜色与原版天空自动一致（环境色直接采样 skyIn）。
2. 白天/夜晚/室内外均正确：昼夜光源切换跟随游戏自身逻辑；室内由 skyDepth 深度掩码天然排除。
3. 架构零重依赖：构建保持 cl 两文件；不引 CommonLib/AddressLibrary（v1）。
4. VK 重写铺垫约束：数据获取保持拦截式（后端无关）；云 march 世界化（标准渲染器技术）。
5. 性能：新链 pass 数由 4 降 2（云 + 合成）；0.83ms 预算在 v1 为**记账指标不设闸**（判据见 §5），超限触发 R9。

**非目标 / 反目标**

- 不重写大气梯度/星星/太阳盘/地平线雾（原版负责，这正是错误面的来源）。
- 不做全替换天空（留给 VK 重写期）。
- 不动 SSR 通路与 Option A 世界锁定裁定（ssr=0 现状不变）。
- 不抄 CS 代码行（GPL-3.0）；每帧同步读回禁令不变；静默承诺不变（无新每帧日志）。
- v1 不做屏幕侧「太阳盘检测」回退通道（重新引入屏幕 pass 违背 4→2 降本目标，见 §4A 裁定）。

## 4. 架构决定

**退役**

- sky_probe.frag（1x2 假太阳估计）及其状态图/迟滞闩锁；
- sky_lut.frag（自研单次散射 LUT、参考 texel、软膝压缩、增益归一全家）；
- sky_comp.frag 的「掩码内替换天空 + 均值归一化增益」部分。

**保留**

- 段 7-end 结构触发、skyIn/skyDepth 入向共享镜像、事件闸/配平/心跳、CopyResource 同帧回写窗口（docs/07 §4）；
- 云 3D 值噪声 FBM 32³ + cloudtemporal ping-pong、sky.preset 分档与 ini 覆盖、knobchk 体系；
- 全部闸链（check1/gates4/enc_gate/dllchk/CI 流程）与观测口径（触发/配平/心跳/desc 一致）。

**新增 A — 真方向采集（Direction Harvest）**

- 方法：扩展现有 VS 常量缓冲扫描基建（camdump 方法论）——普查定位「平行光 shadow-cast view 矩阵」所在槽位/条目/偏移；正交化提取方向向量。昼 = 太阳、夜 = 月亮（跟随游戏自身光源切换，夜晚是否有月亮矩阵由普查实证，不预设）。
- 普查通道：**用仓内 camdump 系 dump 通道**（sky 会话下同样可用的全槽普查 + 正交过滤），RenderDoc 仅作可选交叉校验；需要用户 1 批短会话（白天 + 夜晚各一次，见 §7 Q3）。
- 矩阵识别（builder Q6 裁定）：**普查钉住（槽位, 条目, 偏移）为主键 + 逐帧校验（正交性/稳定性闩锁）+ ini 覆盖口（camslot 同款模式）+（重）锁记录日志**。不做逐帧内容猜测；太阳盘一致性只作普查期验证通道，不做运行时依赖。
- 节流：沿用「每帧一次 staging 拷贝 + 下帧 Map」模式，零同步读回。
- 相机解耦（builder Q3/Q4/Q5 裁定）：相机常量缓冲捕获从 ssr 门解耦（sky=1 同样运行）；**平移列解析进 T8**（普查定位「相机世界坐标」的正确来源——注意视图矩阵平移列不是世界坐标，需普查甄别）；云层锚定**绝对海拔**（slab = 世界 2-8km），噪声坐标锚定世界 XZ ⇒ 山顶/移动视差正确；普查若无法定位世界坐标来源，回退相机相对 slab 并在文档记为已知限制。fov/纵横比**从捕获的投影矩阵反推**（fov mod/第三人称/分辨率变化均正确），ini 仅作冷启动回退值并入 `天空:` 回显与 knobchk。
- 降级行为（builder Q1 裁定）：**锁定丢失 ⇒ 冻结上一好方向**（记录一次状态转换日志）；**从未锁定 ⇒ 云 pass 不出画，合成 = skyIn 原样**。不新增任何屏幕侧探测 pass。

**新增 B — 云 pass v2（世界化）**

- 光线构造：qchain 四元数 + 反推 fov 构造真实世界方向光线；地平线为几何判据（rd.y）；
- 云层：世界 2-8km 高度 slab march（现 march 骨架复用，档位化参数）；
- 直接光照：采集的方向 A（太阳/月亮自动切换）；环境光照：直接采样该像素（及小邻域）skyIn 天空色 ⇒ 颜色匹配由构造保证，不再有归一化/参考 texel/压缩；
- 遮挡：skyDepth 深度掩码保留（室内/地形天然排除）；
- 风漂移：保持帧驱动（真游戏时间接入列为后续可选）；
- 时域历史（builder Q2 裁定）：**加旋转重投影**（T9 子项）——远场云只差旋转，用上一帧/本帧四元数差在 shader 内重投影历史 UV（prev quat 入 push constant pad 位），快摆时按转角衰减历史权重 ⇒ 「快摆无拖影」验收项保持可达。载入/切镜头由「首 N 帧历史杀闸」覆盖。

**新增 C — 合成 v2**

- out = mix(skyIn, cloudColor, alpha·softMask)：不归一化、不增益、无参考量；掩码判据仍为 skyDepth 空深度。
- 原版天空（梯度/太阳盘/星星/2D 云层）逐位保留，仅在我们的体积云覆盖处混合。

## 5. 观测与验收

- 日志：现有 [sky] 心跳/配平/闸账保留；探针专有输出退役（静默承诺内做减法）；新增一次性「方向锁定/丢失/重锁」状态行（非每帧）。
- 视觉验收（游戏会话检查点）：云的受光方向随一天时刻真实变化（关键判据：太阳在西 ⇒ 云受光面在西）；云色与天空色无缝（无「贴纸感」）；夜晚云暗蓝灰不发光（若普查证实夜晚无月亮矩阵，则以冻结/近似行为的记录口径验收）；室内无痕；快摆无拖影（旋转重投影后）；正午/黄昏/夜晚三时段截图；山顶场景云在头顶上方远处（绝对海拔锚定生效，若回退相机相对则记为已知限制）。
- 性能验收（builder Q7 裁定）：[sky] 路径均值为**记账指标**（当前口径 = 提交 + fence 等待的 CPU 可见延迟，非 GPU 时间戳）；v1 不设硬闸，**均值 >1.0ms ⇒ 触发 R9 异步 fence**（预授权在案）。
